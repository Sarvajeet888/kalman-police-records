KALMAN SYSTEMS - NODE / NPM VERSION

Requires Node.js 24 or newer (https://nodejs.org/).

1. Extract the ZIP.
2. Open the extracted folder containing package.json.
3. In that folder, open Command Prompt / Terminal.
4. Run: npm install
5. Run: npm start
6. Open: http://localhost:3000
