02 / Concept one · Tables

A table is an organised collection of records.

Think of it as a register: each row is one record, and each column is one detail.

TABLE: complaints3 rows · 4 columns

Simplified view: selected columns from the project’s database, with sample data.

TABLE

A collection

All complaints are stored together.

ROW

One record

One row describes one complaint.

COLUMN

One attribute

For example: id, title or status.

03 / Concept two · Keys

How does evidence know which case it belongs to?

A primary key identifies a record. A foreign key connects it to another table.

complaints PARENT TABLE
id PKtitle
101Missing laptop
102Lost wallet
evidence CHILD TABLE
id PKlabelcomplaint_id FK
201Receipt101
202CCTV clip101
203Wallet photo102
One complaint → many evidence items.

Primary key = unique identity

Two complaints cannot have the same primary-key value.

Foreign key = valid connection

Evidence must refer to an existing complaint. An invalid ID is rejected.
